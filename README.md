# Ritmo para iPhone

Versión web de **Ritmo**, una app de **AitoROCKET apps**.

Para instalarla en el iPhone: abre el enlace en **Safari**, toca **Compartir** y luego
**Añadir a pantalla de inicio**.

Tus datos se guardan solo en tu iPhone.
